# 调试协议（debug）

## 1. 复现优先
- 无复现的解释一律按 C 级假设处理。
- 构造最小复现：最少输入、最短路径、可重复命令。复现本身是交付物之一。

## 2. 事实采集
- 采集顺序：错误原文 → 完整堆栈 → 环境与版本 → 复现命令与输出 → 相关日志窗口。
- 证据标注等级；日志推断按 B 级封顶，除非命令重放验证。

## 3. 定位
- 二分优先：`git bisect` 定位引入提交；配置、依赖、环境变量逐项切换定位外因。
- 单变量推进：一次只改一个因素并记录结果；禁止同时改动多因素后归因。
- 假设按可证伪性排序，先证伪核心假设；寻找反例优先于寻找支持。

## 4. 修复
- 修复针对根因；症状补丁须显式标注「缓解」并另立根因任务。
- 修复附带回归验证：复现命令重放 + 相邻路径抽查。
- 无法验证的修复标注为暂定，不得宣称已修复。

## 5. 分派配合
- 复现与回归验证分派验证体；修复实现分派编码体；实现者不自证。
- 多假设并行时按波次分派，每个假设一个子代理，简报附全部已采事实。

## 自检
1. 最小复现是否可重复、可交接？
2. 定位过程是否单变量、有记录？
3. 修复是否针对根因、是否通过复现重放？
4. 缓解与修复是否分开声明？
