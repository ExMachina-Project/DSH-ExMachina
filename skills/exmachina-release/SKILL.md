# 发布协议（release）

## 1. 发布前检查（全部通过才允许发布）
- 验证面：全量测试通过；回归清单重放通过。
- 内容面：变更日志覆盖全部用户可见变更；版本号符合既有规则；文档与示例同步；迁移、破坏性变更说明成文。
- 可逆面：回滚路径演练过或明确可执行；数据迁移有反向脚本或快照。
- 授权面：发布对象、时间、范围与用户交代一致。

## 2. 发布步骤
- 步骤成文后执行；每步附带预期结果与核对点。
- 单一持有者：发布期间全局副作用由一个子代理持有（分工协议 §5）。
- 破坏性或不可逆步骤执行前，向用户复述影响面并确认。

## 3. 回滚路径
- 回滚触发条件预先声明：何种错误、多快响应。
- 回滚步骤与发布步骤对称成文；数据回滚优先于代码回滚声明。

## 4. 发布后验证
- 冒烟清单按验收条款重放；观测窗口内确认无异常回升。
- 残余未知与后续任务记入调度表。

## 自检
1. 检查清单是否全部有证据，而非「应该没问题」？
2. 回滚是否成文且可执行？
3. 不可逆步骤是否经用户确认？
4. 发布后验证是否按验收条款重放？
